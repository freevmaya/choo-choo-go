🎮 О проекте
"Чух-чух поехали!" — это логическая 3D-игра, в которой игроку предстоит собирать железную дорогу из разрозненных фрагментов, управлять паровозиком, цеплять вагоны и доставлять грузы и пассажиров к нужным станциям.

Основные особенности
🛤️ Сборка железной дороги — конструирование путей из фрагментов разной конфигурации

🚆 Управление паровозиком — движение вперед/назад, сцепка и отцепка вагонов

🔀 Переключение стрелок — выбор маршрута движения

📦 Логистика — доставка грузовых вагонов и пассажиров к пунктам назначения

⏱️ Ограничение по времени — дополнительные испытания на скорость

🏆 Система достижений — очки, звания и собранные предметы

Игровые механики
Механика	Описание
Сборка путей	Игрок собирает железную дорогу из хаотично разбросанных фрагментов
Управление составом	Паровозик может двигаться вперед/назад, цеплять и отцеплять вагоны
Стрелки	Пользователь может переключать стрелки для выбора маршрута
Типы вагонов	Вагоны отличаются по цвету, типу (груз/пассажиры) и пункту назначения
Задания	Доставка вагонов к тупикам с совпадающим названием или цветом
🎯 Игровой процесс
Цель игры
Провести паровозик от начала железной дороги до пункта назначения, собирая по пути вагоны, пассажиров и призы, решая логические задачи по правильной стыковке и доставке.

Как играть
Выберите уровень — игра состоит из нескольких уровней-головоломок

Соберите железную дорогу — размещайте фрагменты путей из инвентаря на игровом поле

Управляйте паровозиком — используйте мышь или тачскрин для управления

Цепляйте вагоны — подъезжайте к вагонам для сцепки, кликайте на вагон для отцепки

Переключайте стрелки — выбирайте нужное направление движения

Доставляйте грузы — приведите вагоны к тупикам с совпадающим цветом или названием

Получайте призы — за успешно выполненные задания начисляются очки

Типы элементов железной дороги
Тип	Описание
StraightTrack	Прямой участок пути
EndTrack	Тупик / конечная станция
CrossTrack	Перекресток (4 направления)
ForkTrack	Тройник с поворотами налево и направо
ForkLStTrack	Тройник: прямо и поворот налево
ForkRStTrack	Тройник: прямо и поворот направо
Свойства тупиков (EndTrack)
cart_name — имя вагона, который нужно доставить на этот тупик

taskName — название задания, активируемое при доставке

color — цвет тупика (должен совпадать с цветом вагона)

🚀 Установка и запуск
Требования
Node.js 14+

MySQL 5.7+ / MariaDB 10.6+

Установка
bash

git clone https://github.com/your-username/choo-choo-go.git
cd choo-choo-go

# Установка зависимостей
npm install

# Настройка базы данных
mysql -u root -p < database/schema.sql

# Запуск в режиме разработки
npm run dev

# Сборка для production
npm run build
